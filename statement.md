# Smart Campus Resource Management System

## Problem Statement

Managing shared college resources manually can lead to booking conflicts, difficulty checking availability, and poor record keeping.

The Smart Campus Resource Management System provides a centralized application for managing campus resources, bookings, users, and maintenance requests.

## Scope

The system covers:

* User registration and login
* Campus resource management
* Resource booking
* Booking conflict detection
* Booking approval and cancellation
* Maintenance requests
* Basic reports

The project is designed as a command-line Java application.

## Target Users

* **Students** – Search resources and request bookings.
* **Faculty** – Check availability and request bookings.
* **Administrators** – Manage users, resources, bookings, and maintenance requests.

## High-Level Features

1. User Management
2. Resource Management
3. Booking Management
4. Maintenance Management
5. Report Generation
